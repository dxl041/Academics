# 会议论文批量四要素分析模板

用于对单个会议的全部或部分 session 论文做快速标题级分析。当论文原文尚未公开（会议刚结束）时，基于标题进行推断。

## 格式

```markdown
### Session X: Session Name

#### ★/☆ N. Paper Title
- **研究背景**: ≤50字，该领域大方向和为什么重要
- **要解决的问题**: ≤50字，论文想要解决的具体技术挑战
- **现有方案不足**: ≤50字，当前方法存在什么 gap
- **本文解决思路**: ≤50字，标题暗示的核心创新点
```

## 标注说明

| 标注 | 含义 |
|------|------|
| ★ | 已获取原文摘要，分析基于摘要内容 |
| ☆ | 论文尚未公开，分析基于标题+领域知识推断 |

## 产出物组织

```
~/Academics/<CONF>/
├── program_papers.md           ← 完整论文日程目录
├── analysis.md                 ← 热点领域综合分析
├── paper_analysis_part1.md     ← 逐篇四要素分析 Part 1
├── paper_analysis_part2.md     ← 逐篇四要素分析 Part 2
├── arxiv_results.json          ← arxiv 搜索结果
└── search_papers.py            ← 可重跑的搜索脚本
```

## 热点领域识别

统计各 session 论文数后，按以下维度分类：

- LLM/大模型推理训练
- Security/侧信道/Rowhammer
- PIM/PNM/存内计算
- ML Accelerators/ML加速器
- Quantum Computing/量子计算
- FHE/全同态加密

## 四要素写作原则

1. **研究背景**：写到足够让不熟悉该子领域的人理解为什么这个问题存在，不写论文具体做了什么
2. **要解决的问题**：精确到论文的具体挑战，不是泛泛的"LLM推理慢"
3. **现有方案不足**：指出当前 SOTA 的具体 gap（如"单层优化忽略层间复用"而非"不够好"）
4. **本文解决思路**：浓缩标题暗示的技术路线，用技术术语（如"LUT-based GEMM"而非"用新方法加速"）
